# VidhAI — AI-Powered Agriculture Platform

**VidhAI** is an intelligent agricultural ecosystem that helps farmers make smarter decisions — crop management, market prices, weather intelligence, disease detection, and more — all in 13 Indian languages.

### Install steps
1. Download the APK above (or from the **Releases** tab).
2. Allow *Install from unknown sources* when prompted.
3. Open the app and complete the farmer/consumer onboarding.

> Note: This build runs in **offline mock AI mode** so every feature works without an internet AI key.
